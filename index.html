    Practical Guide: Designing & Securing an Enterprise Network

    A complete, field-tested methodology for designing, securing and supervising a Local Area Network — from the first technical audit all the way to penetration testing and verification. Built on a real enterprise deployment with industry-standard tools (Cisco, pfSense, Zabbix), fully simulated in GNS3, then generalized so it applies to any organization.

    • Diagnosis — hardware inventory, risk matrix, requirements document
    • Architecture — collapsed-core (Core L3 + Access L2), scalable by design
    • Segmentation — 6 VLANs (802.1Q), VLSM addressing, management VLAN 99
    • Stability — Rapid-PVST+ with sub-two-second convergence on link failure
    • Perimeter — pfSense sub-interfaces, per-VLAN DHCP, NAT, default-deny
    • Defense in depth — extended ACLs, Port Security, DHCP Snooping, DAI
    • Access — 802.1X/RADIUS with AAA, IPSec site-to-site, OpenVPN SSL
    • Supervision — Zabbix on isolated VLAN 50, SNMP + Syslog, dashboards
